## Public dictionary contract

`MarketService.normalize_salary(raw)` accepts a salary string or None and returns exactly these keys:

| Key | Meaning |
| --- | --- |
| salary_lower, salary_upper | Numeric bounds in the explicit source currency, with thousand/million multipliers expanded; None for unknown bounds. Fixed amounts repeat the same bound. |
| salary_midpoint | Numeric midpoint only for a valid fixed/bounded amount with both explicit currency and period. None for missing units, invalid/inverted amounts, single bounds or nonnumeric offers. |
| salary_currency | VND, USD, EUR or None, from explicit tokens/symbols; triệu/tr is only a multiplier. |
| salary_period | MONTH, YEAR, HOUR, DAY or None, only from the salary field. |
| salary_basis | gross, net or unknown; no basis conversion. |
| salary_kind | fixed, bounded, lower_bound, upper_bound, negotiable, competitive or unknown. |
| salary_status | valid (explicit VND/month target), parsed (other complete native units), review (incomplete/invalid), excluded (negotiable/competitive, retained for EDA). |
| salary_reason | eligible_vnd_month, non_vnd_month, missing_currency, missing_period, missing_currency_and_period, single_bound, negotiable, competitive, missing_salary, invalid_amount, negative_amount, inverted_range or conflicting_currency/period/basis. |
| salary_target_vnd_month | Midpoint only for valid explicit VND/MONTH fixed/bounded values; otherwise None. Gross/net is retained as published, never converted. |

Numbers use Decimal during parsing/arithmetic and return ordinary numeric values in the dictionary. Dot/comma decimals with one or two fractional digits are accepted; valid groups of three digits are thousands separators. Malformed grouping is review. Thousand/million multipliers apply to the common range unit or separately stated endpoint units. Nonpositive, inverted and extreme amounts above 10^15 are review. Unrecognized residual text, extra amounts and conflicts are review rather than guessed targets. Parentheses are accepted around gross/net only; ambiguous accounting-style amounts stay in review.

`salary_report(source_id=None)` returns rows, row_count, target_n, source_counts, reason_counts and status_counts. None selects every approved source; a source ID selects that source. Every file is verified through preview(limit=None). Each row contains source_id, one-based source_row, original job_id/job_url, raw_salary and the normalization dictionary. Only raw['salary'] supplies evidence. In particular the first real 2023 JD mentions tháng, but its salary field lacks the period: bounds remain 15m/25m, midpoint and target remain None.

`salary_exports(report)` returns four CSV strings, with empty cells for None:

- raw.csv: source identity and original salary field for all rows.
- normalized.csv: identity, raw salary and every normalization field for all rows.
- status.csv: source/status/reason counts, n and target_n.
- review.csv: every row without an eligible VND/month target, including negotiable and separate native units.

The independent `pages/5_Luong.py` imports MarketService, renders the all-source table and reason/status/source totals, switches sources, downloads all four UTF-8 BOM CSVs, and lets users inspect a salary string without adding it to market data. app.py and shared README/pyproject remain untouched by T09.
