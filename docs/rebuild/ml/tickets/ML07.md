## What to build

Chạy lệnh train Ridge trên dữ liệu thật đã chấp nhận, xem baseline và kết quả validation trên trang run.

## Acceptance criteria

- [ ] Readiness/gate phải đạt trước fit; preprocessing/encoder/imputer/scaler chỉ học train, feature schema có phiên bản.
- [ ] Ridge alpha>0 tự khởi tạo; cấu hình/budget/target transform khóa trước test; không pretrained hoặc fixture training.
- [ ] Lưu candidate pipeline, config/library versions, baseline trung vị train, prediction và MAE/RMSE đơn vị gốc; bảng UI từ kết quả thật.
- [ ] Run lỗi không thay active model; Ridge chưa được promote chỉ vì là model đầu tiên hoặc validation tốt.
