# Tách huấn luyện bằng lệnh khỏi dashboard dùng model đã lưu

Ngày 28/10/2026, người dùng chốt huấn luyện bằng lệnh riêng, dashboard Streamlit dùng model đã lưu để demo trực tiếp trên máy. Dashboard có dữ liệu đã chuẩn bị và hỗ trợ tải CSV/XLSX lên để chuẩn hóa, xem lỗi và dự đoán hàng loạt; việc tải file lên không tự khởi chạy huấn luyện. Cách vận hành này giúp tái lập mô hình và giữ trải nghiệm demo ổn định.
