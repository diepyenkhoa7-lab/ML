# Public job metadata collection

44 JobPosting objects collected from public pages on 2026-10-18.

See manifest for URLs, capture/code checksums and access status. No account, paid API, CAPTCHA solver or hidden endpoint was used. Raw JSON-LD and HTML cache stay local because an open dataset redistribution license was not declared. Public URL, title, employer and minimal derived salary evidence are retained in versioned coursework tables; no salary is inferred for negotiated/hidden/censored records.

Original CareerLink pass: later audit found 42 HTTP 200 challenge pages; no JobPosting from those pages was used. Collector was fixed to stop on these responses. JobOKO pass uses the corrected collector.
